# Kendrick Ng — Portfolio

A responsive single-page portfolio built with React, TypeScript, and Vite. The visual direction is based on the editorial sketch in [`docs/design/kendrick-site-sketch.png`](docs/design/kendrick-site-sketch.png): generous white space, oversized typography, fine architectural lines, and a simple monochrome palette.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploying to Vercel

Import this GitHub repository into Vercel. Vercel will detect Vite automatically and use `npm run build` with `dist` as the output directory.
